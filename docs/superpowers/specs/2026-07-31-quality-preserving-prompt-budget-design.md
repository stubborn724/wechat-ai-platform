# 保质量的提示词 Token 优化设计

## 目标

在 ERP 产品图文仿写任务中减少重复输入 Token，同时保持投喂文章的文字/图片槽位顺序、品牌背景规则和固定页脚不变。

## 设计

HTML 解析器继续作为文章结构的唯一来源：原文图片位置会被转换为有序 `image-N` 槽位，最多选择前五个普通槽位生成；少于槽位数时未返回的槽位保持为空，多出的图片不插入正文。二维码及固定联系方式由页脚流程处理，不计入正文图片槽位。

ERP 图生图模式将完整的图片背景知识库交给一次 HTML 槽位内容 Agent。该 Agent 必须为每个已选择槽位返回可直接用于图生图的完整 `prompt`。后续每张图生图请求只携带产品保真硬约束和该槽位的最终提示词，不再把同一份背景知识库重复发送五次。

## 质量门槛

只有存在完整背景知识库且每个选择槽位均返回非空图像提示词时，才允许进入 ERP 图生图。缺少任一提示词会明确失败并停止发布，而不是使用模糊关键词降级生成。这样减少的是重复上下文，不是背景约束或文章格式约束。

## 观测

继续使用现有的定时任务模型用量账本；本次测试验证 Prompt 组装路径，实际运行日志继续记录总输入、输出 Token 与图片调用数量。后续可在不改变生成行为的情况下扩展为按 Agent 标签分组统计。
