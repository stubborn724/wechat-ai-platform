# 结构化视觉约束直传设计

## 目标

让参考图片的视觉分析结果成为最终生图提示词的必经输入，提升图文与纯图片仿写的构图、镜头、光影、色调、版式和主体关系还原度，同时排除文字、品牌、水印与二维码。

## 问题

当前 HTML 图文仿写允许内容 Agent 返回图片 `prompt`。该字段为空、过短或泛化时，图片服务会退回 `keywords` 生图，视觉分析 Agent 的结构化结果没有程序级约束，导致图片质量与参考图差异过大。

## 设计

新增统一的“视觉约束提示词合成器”。输入包括：

- 视觉分析 Agent 的 `subject`、`scene`、`composition`、`camera`、`lighting`、`color_palette`、`visual_style`、`details` 和 `mood`；
- 内容 Agent 生成的新主体或图片需求关键词；
- 可选的补充提示词。

合成器以高相似度策略输出最终提示词。参考图的构图、镜头、光影、色调、版式风格和主体关系为强制保留约束；新主体覆盖原主体描述。补充提示词仅用于增强，不得覆盖或删除视觉约束。最终提示词始终追加“不得包含文字、品牌、水印、签名、标签、二维码”的负向要求。

## 调用边界

- HTML 图文仿写：内容 Agent 只返回新主体与可选补充描述；程序使用图片槽位对应的视觉分析结果合成最终提示词。
- 即时纯图片与定时纯图片：共享图片仿写服务改为调用合成器，默认高相似度。
- 定时图文参考图流程：按正文图片占位符复用同一合成器，保持一图一生成的现有语义。
- 旧 LangGraph 图片节点：改为传递 `ImageRequirement.prompt`；缺失时使用合成器或明确报错，禁止静默退回关键词。

## 异常与边界

- 二维码图片在合成之前已被过滤，不能形成最终提示词。
- 视觉分析字段缺失时，合成器保留可用字段并使用补充提示词；没有任何视觉字段时才使用关键词降级，并记录警告。
- 生成服务只接收合成器最终输出，不再直接使用内容 Agent 的原始图片 `prompt`。
- 模型返回图片失败时维持现有的单图失败隔离策略。

## 验证

- 最终提示词包含新主体、构图、镜头、光影、色调和风格等可用视觉字段。
- 内容 Agent 的空提示词不会导致只按关键词生图。
- 补充提示词不能删除无文字、无品牌、无水印、无二维码限制。
- 图文、即时纯图片、定时纯图片与旧 LangGraph 节点调用相同的合成器。
