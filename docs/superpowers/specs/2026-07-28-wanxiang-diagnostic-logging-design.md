# 万相图片生成诊断日志设计

## 目标

在后端控制台输出足以定位万相图片生成失败原因的结构化日志，并禁止仿写任务用随机图库图片伪装为生成成功。

## 日志边界

- 提交任务前记录模型、尺寸、提示词字符数和不超过 240 个字符的摘要；不得记录 API Key。
- HTTP 非 200 时记录状态码和不超过 800 个字符的响应摘要。
- 获得异步任务 ID 后记录任务 ID；轮询完成时记录状态、耗时和失败消息摘要。
- 网络异常记录异常类型和消息摘要；轮询超时记录任务 ID 与尝试次数。
- 万相失败返回 `None` 时，图片策略记录“随机图库回退已阻止”，并将失败显式交给上游。

## 行为

`WanxiangImageService` 继续以 `None` 表示没有可用生成图片，但每个失败出口必须先记录诊断上下文。`DashScopeImageGenService` 不再返回 `picsum.photos`，让调用方保留图片槽位或标记任务失败；随机图库只允许在显式演示模式使用，本次仿写链路不启用该模式。

## 验证

- 模拟 HTTP 400 时日志包含状态码和响应摘要，不包含密钥。
- 模拟万相失败时图片策略返回 `None`，不返回 `picsum.photos` URL。
- 模拟轮询失败时日志包含任务 ID、状态和失败消息。
