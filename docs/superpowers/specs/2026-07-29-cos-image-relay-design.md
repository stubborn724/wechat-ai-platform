# 腾讯 COS 图片中转设计

## 目标

为定时 ERP 图文任务增加独立的腾讯 COS 临时图片中转能力，使百炼万相能够读取 ERP 产品原图，并使最终生成图片可以被微信公众号中转站访问。现有 MinIO 继续作为本地素材库，不迁移历史文件，也不改变素材管理、视频、水印等模块的存储职责。

## 方案选择

采用“COS 临时中转 + MinIO 本地归档”的双存储方案。

- COS 只存放当前生成任务需要交给外部服务读取的临时图片。
- MinIO 继续保存本地素材库、自动归档素材和其他业务文件。
- ERP 原图先由后端安全下载，再上传 COS 私有 Bucket，并生成短时有效的 HTTPS 签名 URL。
- 万相使用 COS 签名 URL 作为图生图参考图。
- 万相返回的 HTTPS 结果图优先直接交给微信公众号；本地归档失败不能把可用的万相 HTTPS 地址替换为 `localhost` 地址。
- 任务结束后删除本次 COS 临时对象；异常分支也通过 `finally` 清理。

没有选择直接替换 MinIO，因为 `StorageService` 同时服务于素材库、视频、水印和内容任务。全量替换会扩大变更范围，并让私有签名 URL 的短时语义污染长期素材 URL。

## 模块边界

### COS 配置

在 `Settings` 中增加以下仅后端可见的配置：

- `cos_enabled`
- `cos_secret_id`
- `cos_secret_key`
- `cos_region`
- `cos_bucket`
- `cos_signed_url_expire_seconds`

密钥只写入 `backend/.env`，不返回前端、不进入数据库、不打印到日志。`.env.example` 只保留空值和说明。

### COS 中转服务

新增 `CosImageRelayService`，只负责四件事：

1. 校验配置完整性。
2. 接收已下载的图片字节并上传到 `temporary/` 前缀。
3. 生成短时有效的私有 HTTPS 签名 URL。
4. 删除临时对象。

服务通过构造函数注入 COS 客户端，便于单元测试，不依赖全局网络请求。对象键使用租户、任务运行记录和随机 ID 隔离，避免并发任务覆盖。

### ERP 图片准备

`scheduled_erp_image_service` 继续负责随机选图、三天防重和本地素材归档，同时为选中的 ERP 原图生成 COS 中转地址。返回对象增加中转 URL 和中转对象键，定时任务只把中转 URL 传给万相。

ERP 原图下载继续经过现有 URL 安全校验和响应大小限制。已入本地素材库的图片可以直接读取 MinIO 字节后上传 COS，避免重复访问 ERP；首次使用则在一次下载中完成本地归档与 COS 中转。

### 万相与公众号交付

图生图模型使用已验证存在的 `wanx2.1-imageedit`。万相生成成功后，正文和封面交付地址优先保留万相 HTTPS 地址；MinIO 归档仅用于本地留存。

公众号发布失败必须向上抛出，`ScheduledTaskRun` 标记为 `failed` 并记录可读错误。只有公众号草稿接口真实返回成功后，运行记录才标记为 `completed`，文章状态才设置为 `draft_saved`。这可以消除此前“日志显示发布失败，但定时任务显示完成”的假成功。

## 数据流

1. 定时调度创建 `ScheduledTaskRun`。
2. ERP API 返回产品元数据和原始图片 URL。
3. 后端安全下载 ERP 图片并归档到本地 MinIO。
4. 后端把同一图片字节上传到 COS 私有 Bucket。
5. COS 返回短时 HTTPS 签名 URL。
6. 万相以签名 URL 为参考图生成 5 至 7 张不同背景图片。
7. 万相 HTTPS 结果图写入文章并由公众号发布器上传微信素材。
8. 公众号草稿保存成功后更新文章和运行记录。
9. `finally` 删除 COS 临时对象；删除失败只记录不含凭证的告警，不覆盖主流程结果。

## 错误处理

- COS 配置缺失：任务在调用 ERP 和万相前失败，错误明确指出缺少的配置名。
- ERP 图片下载失败：任务失败，不用随机图片替换产品图。
- COS 上传或签名失败：任务失败，不回退到 `localhost`。
- 万相图生图失败：任务失败，不把 ERP 原图伪装成生成结果。
- 微信草稿保存失败：任务失败，文章保留为可排查状态，不标记 `draft_saved`。
- COS 清理失败：主任务结果不受影响，但后端记录对象键和错误类型，便于后续清理。

## 安全设计

- Bucket 保持私有读写。
- 签名 URL 默认有效期 1 小时，仅覆盖单个对象。
- 日志不输出 SecretId、SecretKey 或完整签名查询串。
- COS 客户端只在后端进程中创建。
- 建议正式环境使用 CAM 子用户，并将权限收紧到指定 Bucket 的 `temporary/*` 前缀。

## 测试与验收

自动化测试覆盖：

- 配置缺失时拒绝启动 COS 中转。
- 上传内容、Bucket、对象键和 Content-Type 正确。
- 签名 URL 为 HTTPS 且有效期正确。
- 正常和异常分支都会删除临时对象。
- ERP 准备结果把 COS URL 而不是本地 MinIO URL传给万相。
- 万相输出优先于本地归档 URL用于公众号交付。
- 微信发布失败时定时运行记录为 `failed`，成功时才为 `completed`。

端到端验收标准：使用主号 `#103` 的草稿模式执行一个临近时间的 ERP 定时任务，日志中能够看到 ERP 选图、COS 中转、万相图生图和微信草稿保存成功；数据库运行记录为 `completed` 且关联文章状态为 `draft_saved`。测试完成后恢复正式发布时间。
