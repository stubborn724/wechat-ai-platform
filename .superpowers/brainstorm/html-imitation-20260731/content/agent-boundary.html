HTML 版式仿写：复用内容分析，新增确定性版式解析

同一个 Agent 负责理解文章“怎么写”；程序负责保留页面“怎么排”。版式变化不等于要新增一个 Agent。

保留：原有结构分析 Agent

输入Markdown / 纯文本
输出标题模式、开头钩子、段落节奏、内容章节、语气
职责稳定无论科技、家居、商业文章，都分析内容组织规律
→

新增：HTML 版式蓝图服务

输入抓取到的 body_html
输出不可变 DOM 模板 + 文本槽位 + 图片槽位
不依赖样式种类边框卡片、角标、黑底小标题、留白、字体和图片位置都原样保留
→

避免：每种版式一个 Agent

问题“豪宅卡片 Agent”“黑色章节标题 Agent”会随样式数量无限膨胀
后果提示词、路由、测试和发布链路重复维护，且新样式总会漏掉
正确扩展点必要时增强通用槽位识别规则，而不是按视觉风格分叉
建议方案：保留现有格式分析 Agent，给它增加可选的 layout_profile 摘要；真正的 HTML 样式复刻由通用 DOM 蓝图服务完成。原有文章仍走现有 Markdown 仿写路径，因此不会被破坏。
